# 排名引擎回归案例

## 情况 4：四支队伍同分

### 类型 II：部分球队在相关球队相互比较中被排出

四队总积分相同，相关球队相互比赛积分同为 3 分；随后相互比赛净胜球为：A 队 +1、C 队 +1、B 队 -1、D 队 -1。

- A 队、C 队属于较高档，只能争夺该同分组的第 1–2 名；如仍无法通过二次相互比较与后续条款区分，再由管理员确认其内部顺序。
- B 队、D 队属于较低档，必须先锁定为该同分组的第 3–4 名；如仍无法区分，只能由管理员确认第 3、4 名的内部顺序，绝不能显示为第 1、2 名或进入出线名额争位。

用于复现的已确认赛果（四队各 3 分）：A 队 2–0 B 队、B 队 1–0 C 队、C 队 2–0 D 队、D 队 1–0 A 队。

## 情况 2：两支队伍同分

### 最后一轮相遇并打平：不绑定固定净胜球数

对两支在出线线两侧同分的球队，系统必须使用实际已确认数据计算，不能把“全组净胜球为 1”或任何固定数值写入推演逻辑。

- 若双方相互比赛积分、相互净胜球、相互进球数，以及全组净胜球、全组总进球均相同，则显示“待公平积分／抽签排名／点球大战确认”。
- 若全组净胜球存在任意差值（包括 1、2、3、4 个及其他值），在双方最后一轮相互打平后，该差值仍应进入对应排名条款并自动分出名次。
- 若全组净胜球相同、全组总进球不同，则应由全组总进球自动分出名次；只有所有适用条款均相同才进入待确认。

回归覆盖：类型 I、II、III 均验证全组净胜球差为 0、1、2、3、4 的场景。
